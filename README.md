# Инструмент визуализации графа зависимостей (Вариант №5)

## 1. Общее описание
Консольное приложение (CLI) для анализа и визуализации графа зависимостей пакетов формата Rust (Cargo) 

На **Этапе 5** реализована генерация PNG файла с графом зависимостей, а также вывод ASCII-дерева зависимостей пакетов с использованием поиска в глубину (DFS).

## 2. Описание всех функций и настроек

### Настраиваемые параметры командной строки (CLI):
* `--package` - имя анализируемого пакета (обязательный параметр).
* `--repo` - URL-адрес репозитория или путь к файлу тестового репозитория (обязательный параметр).
* `--test-mode` - флаг режима работы с локальным тестовым репозиторием.
* `--version` - версия анализируемого пакета (обязательный параметр).
* `--output` - имя сгенерированного файла с изображением графа (по умолчанию `graph.png`, требуется расширение `.png`).
* `--ascii-tree` - флаг режима вывода зависимостей в формате ASCII-дерева.
* `--filter` - подстрока для фильтрации пакетов (по умолчанию пустая строка).
* `--reverse` - флаг режима для вывода обратных зависимостей

### Основные функции модуля `src/main.py`:
* `create_parser()` - создает и настраивает парсер аргументов командной строки (`argparse.ArgumentParser`).
* `validate_args(args)` - проверяет корректность всех введенных параметров (непустые значения, проверка существования файла в тестовом режиме, проверка протокола `http/https` в обычном режиме, проверка расширения `.png`).
* `print_config(args)` - выводит все настраиваемые параметры в формате `ключ = значение`.
* `fetch_cargo_dependencies(repo_url, package, version)` - выполняет HTTP-запрос к API репозитория Cargo (`/api/v1/crates/{package}/{version}/dependencies`), разбирает полученный JSON-ответ и извлекает список уникальных имен прямых зависимостей (`crate_id`).
*  `get_latest_version(repo_url, package)` - выполняет HTTP-запрос для получения актуальной версии зависимых пакетов.
* `load_test_repo(file_path)` - загружает описание тестового пакета из локального JSON-файла.
* `build_graph_dfs(package, args, test_data, visited, graph)` - рекурсивно строит граф зависимостей методом DFS с учетом фильтрации и защитой от циклов.
* `print_graph(graph)` - выводит построенный граф зависимостей в консоль.
* `find_reverse_dependencies(target_pkg, args, test_data)` - определяет список пакетов, зависящих от `target_pkg`, путем запуска рекурсивного обхода `build_graph_dfs` и проверки достижимости целевого узла.
* `print_reverse_dependencies(target_pkg, reverse_deps)` - выводит найденные обратные зависимости в консоль
* `generate_graphviz_dot(graph)` - формирует текстовое представление графа на языке Graphviz
* `save_graph_png(dot_code, output_path)` - вызов программы Graphviz и создание изображения графа
* `print_ascii_tree` - рекурсивное построение дерева зависимостей
* `main()` - точка входа в приложение, выполняющая валидацию параметров, вызов функции для построения дерева зависимостей пакета и генерации изображения.
